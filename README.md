# paint-rs (Vibeclones mirror)

Hosted copies of older browser (WebAssembly) builds of [Paint.RS](https://github.com/daijro/paint.rs), a clean-room Paint.NET reimplementation in Rust by daijro. The author's own site, [playground.daijro.dev/paint-rs](https://playground.daijro.dev/paint-rs/), serves only the newest version; this repo keeps older versions open-able so the timeline can be explored in a browser. This repo only mirrors upstream release zips; the code is theirs.

- Latest: `/paint-rs/latest/`
- Specific version: `/paint-rs/v<version>/`
- Version list: `/paint-rs/versions.json`

Each version folder is the unmodified contents of upstream's `paintrs-web-<version>.zip` release asset, including its license files. Upstream license: GPL-3.0-or-later. A scheduled workflow mirrors new releases.
